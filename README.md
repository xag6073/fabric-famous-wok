# ModWok

## Setup

Before starting run these two scripts in order

1. fabric genSources
2. `Data Generation` (`./gradlew runDatagen`)
   1. Verify that the `src.main.generated` directory is created
   2. Make sure that the `src.main.generated.data.modwok` subdirectories contain the .json files (might need to run `DataGeneration` twice)

Then you can start the client
